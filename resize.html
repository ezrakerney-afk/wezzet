    Questions

    What does Keep shape do?

    It stops the photo from stretching. Fill in just the width or just the height and the other side is worked out for you. Fill in both and the image fits inside that box.

    Are my photos uploaded?

    No. Resizing happens in your browser.

    Can I make an image bigger?

    Yes, but it won't gain detail. Big jumps can look soft.

    About resizing images

    Resizing changes an image's pixel dimensions. Keep the aspect ratio locked so the picture does not stretch.

    Shrinking and enlarging

    Making an image smaller keeps it sharp and cuts the file size. Enlarging invents pixels, so the result looks soft; start from the largest original you have.

    Sizes for common uses

    A full-width web image rarely needs to be more than 1,600 to 2,000 pixels wide, and 1,200 pixels suits most blog posts and emails. A profile picture is fine at 400 × 400.

    Printing

    Printers need about 300 pixels per inch for sharp results: 1,800 × 1,200 pixels for a 6×4 inch print and 2,400 × 3,000 for 8×10.

    The DPI value stored in a file does not change how it looks on screen; only the pixel dimensions matter there.
