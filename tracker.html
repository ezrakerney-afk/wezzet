          Where to report

          Places a tip can go, and which ones can pay. You always send it yourself.

          FBI

          The fastest route when funds can still be frozen. No set reward, but this is where action happens.

          ic3.gov · tips.fbi.gov
          Rewards for Justice

          Up to $5 million for information that disrupts North Korea's money laundering. Names, companies and services count most.

          rewardsforjustice.net
          Lazarus Bounty

          Bybit pays a share of funds frozen because of your trace. Only for money from the Bybit theft. Check it's still open.

          lazarusbounty.com
          The exchange itself

          When funds are landing at an exchange right now, its compliance or law-enforcement contact can freeze them within hours.

          Find the contact on the exchange's site

          Always check a lead by hand first, never contact the wallets' owners, and don't post findings publicly before you tip.

          Leads

          Alerts you promoted. Add notes, then build a tip draft to copy into Rewards for Justice, the FBI or an exchange. Nothing is ever sent from here.

          Settings

          Pause everything

          The watcher stops at its next check and makes no API calls until you turn this off.

          Reporter profile

          Added to the bottom of every report, so you never type it again. The FBI, Rewards for Justice and Lazarus Bounty don't let other apps sign in or send reports for you, so Chain Watch does everything up to the last step: it writes the full report, copies it and opens the right form. You paste and press send. Saved encrypted.

          Automation

          Built in means Wezzet does the checking itself and you don't need to set up anything else.

          Checking

          Alerts

          Browser notifications use the same switch as Messages: turn notifications on once in Messages on each device. Telegram needs the bot token and chat ID below.

          API keys

          All optional. The built-in watcher works without keys; a free Etherscan key makes Ethereum checks faster and adds BNB Chain. Keys are encrypted and never shown again. Leave a box empty to keep the saved key.

          Watcher token

          Only needed if you run your own watcher script. Put it in that script's repo as the WEZZET_TOKEN secret. It's shown once, and making a new one stops the old one.

          Where and how to report it

          Press a button: a finished report written for that site (with your contact details) is copied and the site opens. Then follow the steps under it: paste with Ctrl+V (or long-press, Paste) and send.
