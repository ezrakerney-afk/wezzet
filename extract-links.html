About Links/bookmarks to CSV

This pulls every link out of an HTML page or a browser bookmarks export into a CSV with the title and URL.

Drop the file above (or choose it), then press Links/bookmarks to CSV. The result downloads right away. Everything runs in your browser, so the file never leaves your device, there is no sign-up, and you can do as many files as you like.

Questions

What happens to my file?

It stays in your browser. Wezzet reads it with JavaScript on your own device, so nothing is uploaded or stored.

Is it free?

Yes. There is no account, no watermark and no limit on how many files you convert.

Does it work on my phone?

Yes. It works in any modern browser on iPhone, Android, Windows, Mac and Linux.

My file is a different format. What now?

Drop it on the any-file converter at /convert. It shows every conversion Wezzet can do for that type of file.
