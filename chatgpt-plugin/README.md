# Wezzet plugin for ChatGPT

Upload package for OpenAI's plugin submission. Zip the contents of this folder (plugin.json, mcp.json, assets/, skills/ at the zip root).

- MCP server: https://wezzet.com/mcp/app (OAuth 2.1 with dynamic client registration)
- MCP Events: `dm.received` (events/list, events/subscribe, events/unsubscribe; Standard Webhooks signatures)
- Docs: https://wezzet.com/plugin
