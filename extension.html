Wezzet extension

Help and support for the Wezzet browser extension.

How to use it

Convert something on a page: right-click an image, video, audio file or link and choose Convert with Wezzet. Wezzet opens in a new tab with the file already loaded.

Ask a question: select some text, right-click, and choose Ask WezzetAI.

Find a tool: click the Wezzet icon in your toolbar and type what you need, like "heic to jpg".

Privacy

The extension collects no data and has no tracking. When you right-click a file, it downloads that one file so it can hand it to the Wezzet tab, and the conversion happens on your own device. Nothing is uploaded to our servers.

It asks for access to all sites only so it can fetch the file you right-click, wherever it is.

Common problems

"Couldn't download that file"

Some sites block downloads from other tabs. Save the file to your computer, then drop it on wezzet.com/convert.

The menu item doesn't show up

Reload the page you're on after installing, or restart the browser.

Something else is wrong

Post in the Wezzet forum or message @WezzetX on X, and we'll help.
