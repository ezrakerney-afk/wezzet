WezzetAI's model server: an open-weight model (Qwen3 4B, Apache 2.0) on llama.cpp, called by wezzet.com/api/ai.
Set a Space secret `API_KEY` to any long random string and give the same value to the site as `WEZZETAI_KEY`.
