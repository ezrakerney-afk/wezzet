Convert colors between HEX, RGB, HSL, HSV and CMYK. Type in any box or pick a color.

How to convert HSL to RGB

First find the chroma: C = (1 −

2L − 1

) × S. Then X = C × (1 −

(H ÷ 60°) mod 2 − 1

) and m = L − C ÷ 2.

The hue picks which channels get C, X and 0: from 0° to 60° it is (C, X, 0), from 60° to 120° (X, C, 0), and so on around the wheel. Add m to each and multiply by 255.

Worked example

hsl(32°, 100%, 50%): C = 1, X = 0.533, m = 0, so the color is (1, 0.533, 0), which is rgb(255, 136, 0).

Reading HSL

Hue 0° is red, 120° green and 240° blue. Saturation 0% is gray. Lightness 0% is black, 100% is white and 50% is the pure color.
