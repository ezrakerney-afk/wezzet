About encryption keys

An encryption key should be random bits from a cryptographically secure generator, not something a person made up. A 256-bit key has 2²⁵⁶ possible values, far beyond any brute-force search.

Key sizes

AES accepts 128, 192 or 256-bit keys. 128 bits is already strong; 256 bits is the common choice for long-term protection.

Formats

Keys are usually shown as hex (64 characters for 256 bits) or Base64 (44 characters). Both hold the same bits.

Handling

Store keys in a secrets manager or environment variable, never in source code, and generate a new one for each purpose.
