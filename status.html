    Questions

    What do the status codes mean?

    2xx is success, 3xx is a redirect, 4xx means the page was not found or is blocked (404, 403) and 5xx is a server error.

    Why does my site show 403 here but work in my browser?

    Some sites block automated checks or visitors from data centers. The check runs from Cloudflare, not from your computer.

    How many redirects are followed?

    Up to 10, so you can spot redirect loops and long chains that slow pages down.

    Is there an API?

    Yes: wezzet.com/api/status?url=example.com returns the chain and headers as text or JSON.

    About HTTP status codes

    Every web response starts with a three-digit status code.

    The five groups

    1xx is informational. 2xx means success: 200 OK. 3xx is a redirect: 301 is permanent and 302 temporary. 4xx is a problem with the request: 404 not found, 403 forbidden, 401 sign-in required and 429 too many requests. 5xx is a server failure: 500 internal error, 502 bad gateway, 503 unavailable and 504 gateway timeout.

    Is it down for everyone?

    If a site fails for you but a check from elsewhere succeeds, the cause is probably your network, DNS cache, VPN or a regional block. If the check fails too, the site itself is having trouble.

    Response time

    Under about 200 milliseconds feels instant. Over one second is noticeably slow.
