Text to decimal (ASCII codes)

Type text to encode it, or paste the encoded form to turn it back into text.

How text becomes decimal

Computers store every character as a number. ASCII covers 128 characters (English letters, digits and punctuation) with codes 0 to 127; Unicode extends the same idea to every writing system and emoji, and UTF-8 stores those code points as one to four bytes.

To encode, look up each character's code and write it in decimal.

Example

The text Hi! is 72 105 33.
