About number bases

A number base is how many different digits a system uses. Decimal (base 10) uses 0 to 9; binary (base 2) uses 0 and 1; octal (base 8) uses 0 to 7; hexadecimal (base 16) uses 0 to 9 and A to F for ten to fifteen.

In every base, a digit's position is worth a power of the base. Decimal 156 is 1×100 + 5×10 + 6×1; the same value is 10011100 in binary, 234 in octal and 9C in hex.

Why programmers use them

Computers store everything in binary. Hex is a compact way to write it, since one hex digit is exactly four bits and one byte is two hex digits. Octal, three bits per digit, survives in Unix file permissions.
