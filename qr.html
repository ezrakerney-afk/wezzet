Questions

Do these QR codes expire?

No. The code holds your link or text directly, so it works forever and there's no tracking.

PNG or SVG?

PNG for screens and documents. SVG for printing at any size.

About QR codes

A QR (quick response) code is a two-dimensional barcode invented by Denso Wave in Japan in 1994. Phone cameras read it directly and open the link or text inside.

What it can hold

Web links, plain text, Wi-Fi login details, contact cards, email addresses and phone numbers. Capacity is up to about 4,000 letters and digits, but short content makes a simpler code that scans more easily.

Error correction

Four levels (L, M, Q and H) let a code still scan with about 7, 15, 25 or 30 percent of it damaged or covered. Higher levels make the pattern denser.

Printing tips

Keep the code at least 2 cm (0.8 in) wide, leave a blank margin around it, use dark modules on a light background, and test it with more than one phone before printing.

A QR code made from a plain link never expires; it works as long as the link does.
