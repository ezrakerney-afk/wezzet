    About PDF tools

    PDF (Portable Document Format) was created by Adobe in 1993 and became an open ISO standard in 2008. It fixes a document's layout so it looks the same on every device and printer.

    Common jobs

    Merge several PDFs or images into one file for a single upload. Split a file to send only the pages someone needs. Compress to get under an email limit. Rotate scanned pages that came out sideways. Convert pages to images, or pull out the text.

    Scanned PDFs

    A scan is a picture of a page, so its text cannot be selected or searched until optical character recognition (OCR) is run on it.

    Before you share

    PDFs can carry hidden metadata such as the author's name, and text covered with a black box can often still be copied. Use proper redaction for sensitive documents.
