What does Title Case leave lowercase?

Short words like a, an, the, and, of, in and to, unless they start the title.

About text case

Sentence case capitalizes only the first word and proper nouns. Title Case capitalizes the main words. UPPERCASE and lowercase change every letter.

Cases used in code

camelCase joins words and capitalizes each after the first (userName). PascalCase capitalizes all of them (UserName). snake_case uses underscores (user_name) and kebab-case uses hyphens (user-name), which is the usual style for URLs and CSS classes.

Title case rules

Style guides differ, but most leave short articles, conjunctions and prepositions such as a, the, and, of and in lowercase unless they start the title.

Long passages in capitals are slower to read and can come across as shouting, so keep uppercase for short labels.
