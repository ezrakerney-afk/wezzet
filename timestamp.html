Questions

What is a Unix timestamp?

The number of seconds since 1 January 1970 00:00 UTC. It is also called epoch time or POSIX time.

Seconds or milliseconds?

Both work. Up to 11 digits is read as seconds, 12 to 14 digits as milliseconds (what JavaScript uses), longer as micro or nanoseconds.

What is the year 2038 problem?

Systems that store the timestamp in a signed 32-bit number overflow on 19 January 2038.

About Unix timestamps

A Unix timestamp is the number of seconds since 00:00:00 UTC on 1 January 1970, known as the epoch. It is a single number with no time zone, which makes it easy for computers to store and compare.

Seconds or milliseconds

A 10-digit value is in seconds (1700000000 is 14 November 2023). A 13-digit value is in milliseconds, as used by JavaScript and many APIs.

Time zones

The timestamp itself is always UTC. Converting it to a date applies a time zone, so the same timestamp shows as different local times around the world.

The year 2038 problem

Systems that store the value as a signed 32-bit number overflow on 19 January 2038. Modern systems use 64 bits, which lasts for billions of years.

ISO 8601

The standard text form for dates is like 2025-03-14T09:30:00Z, where Z means UTC.
