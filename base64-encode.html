Base64 encode and decode

Runs entirely in your browser with the Web Crypto API. Nothing is sent or stored.

About Base64

Base64 turns binary data into text using A–Z, a–z, 0–9, + and /. Every 3 bytes become 4 characters, so the result is about 33 percent larger; = signs pad the end when the input is not a multiple of 3 bytes.

Example

The text Hi! encodes to SGkh.

Where it is used

Email attachments, data URIs in HTML and CSS, JSON fields that hold files, and HTTP Basic authentication. The URL-safe variant swaps + and / for - and _.

Base64 is an encoding, not encryption: anyone can decode it, so never use it to hide secrets.
