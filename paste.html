Questions

Who can see my paste?

Anyone with the link. Links are random and not listed anywhere, but don't save passwords or private details.

How long is it kept?

For the time you pick, counted from the last edit. You can edit or delete it from the same browser you saved it in.

Can AI agents use it?

Yes. Open wezzet.com/api/paste/new?text=hello to save and wezzet.com/api/paste/ID to read. Full guide: tools.txt.

About sharing text snippets

A paste is a piece of text saved at a link so you can share it without sending a file. It suits logs, code, configuration and long messages that chat apps would mangle.

Before you share

Anyone with the link can read a paste, so remove passwords, API keys, tokens and personal details first. If a secret has already been shared, change it; deleting the paste is not enough.

Tips

Share the smallest part that shows the problem, say what you expected and what happened, and include the exact error text. Choose an expiry time if the content only needs to exist for a short while.
